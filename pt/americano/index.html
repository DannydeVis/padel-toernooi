Perguntas frequentes

O Americano padel funciona offline?

Sim. Depois do primeiro carregamento, o PadelBracket funciona completamente offline. O torneio é guardado no dispositivo mesmo que fechem o navegador.

Preciso de uma conta?

Não. Sem registo, sem login. Abre a app e cria o teu Americano diretamente, totalmente grátis.

Para quantos jogadores funciona o Americano?

O PadelBracket suporta de 4 ou mais jogadores para o Americano. Com um número ímpar de jogadores (5, 7, 9...) um jogador descansa a cada ronda automaticamente.

Como funciona o Americano padel?

No Americano, os pares mudam a cada ronda seguindo uma rotação fixa. Cada jogador joga com e contra todos os outros. Os pontos acumulam-se por jogador e quem tiver o total mais alto vence.

Qual é a diferença entre Americano e Mexicano?

No Americano, os pares são determinados antecipadamente através de rotação fixa. No Mexicano, os pares são reatribuídos após cada ronda com base na classificação atual: primeiro e segundo jogam contra terceiro e quarto.

Como podem os participantes acompanhar em direto?

Usa o botão Partilhar na app para gerar um link único. Os participantes abrem-no no telemóvel e veem a classificação em direto, sem conta nem instalação.

Quantos campos são necessários para um Americano?

Depende do número de jogadores. Com 8 jogadores bastam 2 campos, com 12 são necessários 3, com 16 são necessários 4. O PadelBracket gere automaticamente o planeamento com base no número de campos disponíveis.

Prontos para jogar?
