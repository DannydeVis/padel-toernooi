Perguntas frequentes

Como funciona o link de inscricao para torneios de padel?

O organizador cria um evento de inscricao no PadelBracket e partilha um unico link com o grupo. Os jogadores abrem o link, escrevem o proprio nome e tocam para se inscreverem. Nao e preciso conta nem instalar nenhuma app para se inscrever.

Os jogadores precisam de criar uma conta para se inscrever?

Nao. Os jogadores so precisam de abrir o link partilhado, inserir o nome e tocar para se inscrever. Nao ha login, nem palavra passe, nem app para instalar.

O que acontece quando o torneio fica cheio?

Quando o numero maximo de jogadores e atingido, quem se inscrever a seguir e colocado automaticamente na lista de espera em vez da lista principal.

A lista de espera avanca automaticamente quando surge uma vaga?

Sim. Se um jogador confirmado for removido, a pessoa seguinte na lista de espera passa automaticamente para uma vaga confirmada.

O organizador pode remover alguem da lista?

Sim. O organizador pode remover qualquer jogador confirmado ou em lista de espera da lista em direto a qualquer momento.

Posso definir um numero maximo de jogadores?

Sim. Ao criar o evento de inscricao, o organizador define o numero maximo de jogadores. Todos os que ultrapassarem esse numero entram na lista de espera.

Como partilho o link de inscricao?

Copia o link ou le o codigo QR gerado pelo PadelBracket, depois partilha-o pelo WhatsApp, iMessage ou qualquer app de conversa que o teu grupo ja use.

O que acontece a lista quando comeco o torneio?

Quando o organizador fecha as inscricoes e comeca o torneio, os nomes confirmados passam diretamente para a configuracao do torneio, prontos para gerar o calendario. Nao e preciso escrever nada de novo.

A funcionalidade de inscricao e gratis?

Sim. Criar um link de inscricao, recolher nomes e gerir a lista de espera sao funcionalidades totalmente gratis, sem necessidade de conta para o organizador nem para os jogadores.

Pronto para recolher inscricoes?

Abre a app, cria um link de inscricao e partilha-o com o teu grupo. Gratis, sem conta, funciona offline.
